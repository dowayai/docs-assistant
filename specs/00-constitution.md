# Засади проєкту (constitution)

1. Специфікація — джерело істини. Код і тести виводяться зі `specs/01-spec.md`; зміна поведінки = спершу зміна специфікації.
2. Кожна вимога має ідентифікатор (FR-xx / NFR-xx), критерії приймання (AC) і хоча б один тест або питання в `eval/`.
3. Відповіді асистента спираються лише на знайдені фрагменти документації; за браку підстав — явна відмова.
4. Кожна відповідь містить цитування джерел (файл + розділ).
5. Конфігурація (модель, база, параметри чанкінгу) — в `src/config.py`/змінних середовища, не в коді логіки.
6. Зміни специфікації фіксуються у `specs/CHANGELOG.md` з обґрунтуванням (матеріал для розділу 5.5 праці).
